Uniqush was dormant between 2019 and 2026, during which several upstream push
APIs it depended on were shut down. An unreleased version fixing that is on
`master`; the [upgrade notes](/documentation/upgrading.html) describe what
changes, and the notes below cover every numbered release back to 1.3.0. The
full commit-level history is in
[NEWS.md](https://github.com/uniqush/uniqush-push/blob/master/NEWS.md) on
GitHub.
